# Historical Project Documents

**Role:** Historical

Files in this directory preserve completed checkpoints, investigations, proposals, and superseded
plans. They remain available as evidence but do not define current status or authorize new work.

Use this order instead:

1. `AGENTS.md`
2. `CURRENT_STATE.md`
3. Current contracts and `DESIGN_SYSTEM.md`
4. Current operational runbooks

When a historical file links to an old SHA, PR, test count, pending item, or “next” action, read it
as a statement about that checkpoint only.
